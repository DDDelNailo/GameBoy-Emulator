GameBoy-Emulator
=================

A small Game Boy emulator written in Python using pygame for display and input.

Features
- CPU, MMU, PPU and basic input emulation
- Loads Game Boy ROMs from the `roms/` folder

Requirements
- Python 3.10+ (or a recent 3.x)
- pygame

Quick start
1. Install pygame:

	pip install pygame

2. Run the emulator with a ROM path (examples):

	python main.py --rom "roms/Pokemon - Red Version.gb"

Notes
- This is a simple, educational emulator and may not fully emulate all hardware behavior.
- See the `roms/` folder for test ROMs and examples.
